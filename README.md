⚠️ Windows Defender / SmartScreen Warning

When running the executable for the first time, Windows SmartScreen may show a warning: "Windows protected your PC / Unknown Publisher".

This happens because the executable is not digitally signed with an expensive Code Signing Certificate. The application is completely safe and open-source.

How to run:

Click on "More info".

Click on "Run anyway

📥 Download & Installation
You can download the latest version of the executable directly from the Releases section:

Go to the [https://github.com/heitorhanzelgontijo-svg/Hobbs-Home/releases/tag/game] page (or check the right sidebar on GitHub).

Look for the latest release (e.g., v1.0.0).

Under Assets, download the .exe file (or the .zip archive).

Run the executable to start the application!
